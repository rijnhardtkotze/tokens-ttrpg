# In-Character Journal

The character's own first-person diary. Personal, fragmentary, written from inside the story. One short entry per session.

Format:

```
## Entry <N> — after session <YYYY-MM-DD-NN>

<5–15 sentences in the character's voice. What stays with them: images, questions, doubts, hunches. NOT a full report — that's the GM session log.>

---
```

---

_Empty. The first entry is written at the end of the first session._
